# C-14 · 诱饵效应

**Decoy / asymmetric dominance effect** · Huber, Payne & Puto 1982（Journal of Consumer Research）

> 标记说明：【来源】= 文献里的内容；【加工】= Claude 的归纳或推断，可质疑。

## 一句话

往两个选项里加一个没人会选的第三个选项，能改变前两个之间的选择——它违反了"无关选项的独立性"这条公理。

## 来源与实验

【来源】两款啤酒：A 便宜但品质一般，B 贵但品质好，选择大致对半分。加入 C：比 B 更贵，品质却不如 B——C 在每个维度上都被 B 压制（"被非对称支配"），没人会选 C。但 C 出现之后，选 B 的人显著增加。C 什么都没做，它只是站在那里让 B 看起来是个明显更好的交易。

【来源】标准选择理论有一条公理叫"无关选项的独立性"——在 A 和 B 之间的偏好不该被一个你反正不会选的 C 影响。诱饵效应直接违反了它，而且违反得很稳定。

## 机制

【来源+加工】对比：C 给了 B 一个显而易见的参照点。人擅长比较，不擅长绝对评估——B 单独看时"贵不贵"很难说，有了 C 之后"B 比 C 便宜且好"一眼可见。理由：选 B 现在有了一个容易说出口的理由。Shafir 等 1993 年提出的"基于理由的选择"理论认为，人选的常常不是效用最大的，而是最容易为自己辩护的。

## 边界与争议

【来源】Frederick 等 2014 年发现把选项从文字描述换成真实产品图片时诱饵效应大幅减弱甚至消失——它可能主要在"数值比较"的情境下有效（把握中等）。

【加工】《经济学人》订阅的经典案例（Ariely 讲的）：纯网络版 59、纯印刷版 125、印刷+网络 125，第二个是诱饵。菜单上一道特别贵的菜、三档定价——"中间那档"往往就是设计者希望你选的。任何"给用户/老板三个方案"的时候，第三个方案的存在本身就是一种引导。

## 与其他节点的关系

- 【加工】它是参照点依赖（C-3）的一个应用：参照点可以被第三个选项人为制造。
- 【加工】决策卫生（H-4）里"相对判断优于绝对判断"利用的是同一个事实（人擅长比较），只是反过来用。
