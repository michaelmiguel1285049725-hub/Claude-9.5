# B-18 · 模糊厌恶

**Ambiguity aversion** · Ellsberg 1961（QJE）

> 标记说明：【来源】= 文献里的内容；【加工】= Claude 的归纳或推断，可质疑。

## 一句话

人不只是厌恶风险（概率已知），还额外厌恶模糊本身（概率未知）——宁愿选"知道赔率"的赌局，哪怕期望值并不更高。

## 来源与实验

【来源】作者是 Daniel Ellsberg，就是后来泄露五角大楼文件的那个人。这是他 1961 年的经济学论文。

【来源】Ellsberg 悖论：罐子里 90 个球，30 个红球，剩下 60 个是黑球和黄球、比例未知。赌局一：选 A 押"抽到红"，或 B 押"抽到黑"——多数人选 A。赌局二：选 C 押"红或黄"，或 D 押"黑或黄"——多数人选 D。矛盾在于：选 A 意味着你认为红比黑多（黑少于 30）；选 D 意味着你认为"黑或黄"比"红或黄"多，也就是黑多于 30。同一个人对黑球数量给出了两个相反的判断。真正的原因是：A 和 D 都是概率已知的选项（1/3 和 2/3），B 和 C 概率未知。

【来源】关键区分：风险 = 概率已知（抛硬币）；模糊/不确定 = 概率未知（新市场的接受度）。这个区分 Frank Knight 1921 年就提出了，Ellsberg 给出了干净的实验，证明它违反期望效用理论——该理论假设人总能给未知情况赋一个主观概率然后照常计算。

## 机制

【加工】本土偏好（投资者过度持有本国资产）、新供应商新渠道新市场被过度回避、病人偏好已知副作用的旧疗法、一个数据完整的平庸方案比一个数据缺失的潜力方案更容易被通过——都是它。

## 边界与争议

【加工】这一条和 B 区其他条目不同——它未必是缺陷。如果概率未知意味着你对情境的模型本身可能是错的，那么回避它有稳健性上的理由（决策理论里有一整套"稳健决策"研究建在这个直觉上）。所以更准确的说法是：模糊厌恶违反了期望效用理论的公理，但"违反公理"和"不理性"是两件事——这正是 A-11 那场争论的核心分歧。
