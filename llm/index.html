给新人的大语言模型拆解

大语言模型只做一件事：
猜下一个词

ChatGPT、Claude 这类模型写出的每一个字，都是同一个动作重复几百次的结果：看着前面所有的字，给「下一个字可能是什么」打分，挑一个接上去，再重复。先亲手当一次模型——

你来当模型 玩具模型 · 概率为手写示意

也可以直接点右边任意一个候选词。多按几次「按概率抽一个」再重来，每次写出的句子都不一样——这就是同一个问题问两遍，AI 回答不同的原因。

下一个 token 的概率分布

这个玩具只看最后一个词来决定下一个，所以写长了容易前言不搭后语。真正的模型会同时看前面的全部内容，而且它那张「打分表」不是人手写的，而是从海量文本里学出来的。

下面按数据在模型里流动的顺序，一站一站拆开这件事。每一站都有可以动手的图。

第 1 站 · Tokenization

把文字切成 token

模型不认识字，只认识数字。第一步，是用一本固定的词表（通常有 5 万到 20 万个条目）把文本切成小块，每一块叫一个 token，再换成它在词表里的编号。

常见的词整块保留，少见的词被拆成碎片：英文 Transformers 可能被切成 Transform + ers。改一改下面的句子试试：

切词器示意切法 · 编号为演示用

为什么不按字母切？太碎，句子会变得很长，计算很慢。为什么不按整词切？词永远切不完，每天都有新词。切成「子词」是两者之间的折中：真实的词表由一种叫 BPE 的算法从语料里统计出来——哪些字母或汉字组合出现得最频繁，就把它们合并成一个 token。

一个副作用：模型看到的是「块」而不是「字母」。这就是为什么早期模型数不清 strawberry 里有几个 r——在它眼里这个词可能只是两三个不透明的编号。

第 2 站 · Embedding

每个 token 变成一串数字

编号本身没有意义——「猫」是 3000 号、「狗」是 3001 号，并不代表它们相似。所以模型给词表里的每个 token 配了一个长长的向量：一串数字，在 GPT-3 里是 12288 个。

这些数字一开始是随机的。训练之后，意思相近的词，向量也会靠得近。下面把上万维的空间压扁成 2 维来看。点两个词，比较它们的向量：

方向也有含义。从「男人」走到「女人」的那一步，和从「国王」走到「王后」几乎是同一个方向。模型没有被告知什么是「性别」，它是从词语在文本里的用法中自己摸索出来的。

第 3 站 · Self-Attention

让词与词互相看：注意力

到这里，每个 token 的向量还是孤立的：「它」的向量并不知道「它」指的是谁。注意力机制让每个 token 回头看前面所有 token，决定从谁那里拿多少信息。这是 2017 年论文《Attention Is All You Need》提出的 Transformer 架构的核心。

做法是：每个 token 从自己的向量算出三样东西——

Q 查询我在找什么样的信息？
K 键我身上有什么样的信息？
V 值如果你关注我，我交给你的内容。

拿我的 Q 和每个人的 K 做点积，得到「匹配分」；用 softmax 把分数变成加起来是 100% 的权重；最后按权重把大家的 V 加起来，作为我的新信息。

点任意一个词，看它在关注谁 权重为示意
完整的注意力矩阵：每一行是一个词在看谁（右上角空着：不能偷看未来）
试试切换「累 / 高」。在「累」这个位置，头 A 主要看向「小猫」；换成「高」，它转而看向「桌子」。而在「它」这个位置，两个名词的权重差不多——因为此时后文还没出现，模型也拿不准。「它」指谁，是在读到后面的词时才解决的。

一层里有许多个这样的「头」并行工作（GPT-3 每层 96 个）。训练中它们各自分工：有的盯住前一个词，有的负责指代，有的追踪句法结构——没有人规定分工，这是自己长出来的。

注意力不知道先后顺序

单看点积，「狗咬人」和「人咬狗」算出来的东西一模一样。所以在第 2 站的向量上还要再叠加一份位置信号。原始 Transformer 用不同频率的正弦波，让每个位置拥有一种独一无二的「波纹指纹」（右图每一行是一个位置）。

现在的模型多用旋转位置编码 RoPE，思路一样：把「我在第几个」写进向量里。

第 4 站 · Transformer Blocks

一层不够，就叠 96 层

注意力之后是前馈网络：每个 token 各自单独过一个小型神经网络。如果说注意力是词与词开会交换信息，前馈网络就是每个词回到座位上消化、查阅「记忆」——研究发现大量事实性知识存在这里。GPT-3 大约三分之二的参数都在前馈网络中。

「注意力 + 前馈」合起来叫一个 Transformer 块。块与块之间有一条残差通道：每一块不会替换掉向量，而是在它上面加一点修改。于是向量像传送带上的工件，一层层被加工，理解逐步加深。

中途叫停：第 N 层的模型在想什么？logit lens · 示意数据
法国的首都是＿＿

研究者发现，可以把中间某一层的向量直接拿去「猜下一个词」（这种方法叫 logit lens）。浅层只会猜「的」「一个」这类常见字；中间层知道答案是个城市；越往后越笃定是巴黎。拖动滑块看它逐层成形。

第 5 站 · Softmax & Sampling

把分数变成概率，再挑一个

最后一层输出的向量，会和词表里的每一个 token 比一比，得出一个分数，叫 logit——词表有 10 万个词，就有 10 万个分数。softmax 把它们变成正数、且加起来正好等于 1 的概率：

p(词ᵢ) = ezᵢ / T ÷ Σⱼ ezⱼ / T

指数会把差距放大：分数只高 1 分，概率就大约是 2.7 倍。然后从这个分布里挑一个。挑法有两个常见的旋钮：

  • 温度 T：先把所有分数除以 T。T 小 → 强者恒强，几乎总选第一名，稳但呆板；T 大 → 分布被摊平，更有创意，也更容易胡说。
  • top-p：只在累计概率达到 p 的那几名里挑，把长尾里离谱的选项直接砍掉。
「我今天早餐吃了＿＿」分数为示意
候选分数 z概率

把温度拉到 0.1 再抽样：几乎全是「面包」。拉到 2.5：连「石头」都可能出现——模型写代码时常用低温，写诗时常用高温。

第 6 站 · Autoregression

一个 token 接一个 token 地写

挑出来的 token 被接到输入的末尾，整个模型从头再跑一遍，得到再下一个……直到它挑出一个特殊的「结束」token。这叫自回归生成。聊天界面里文字一截一截冒出来，就是这个原因：它真的是一截一截算出来的。

生成的循环：上一步的输出，是下一步的输入
  • 上下文窗口。模型每一步能看到的总长度有上限。GPT-3 是 2048 个 token；如今的模型可以到几十万甚至上百万。超出窗口的内容，它就看不见了。
  • KV 缓存。每生成一个 token 都要把整个模型跑一遍。为了不重复计算前文的 K 和 V（第 3 站），推理时会把它们存起来复用。
  • 「想」要花 token。模型每输出一个 token，内部的计算量是固定的。让它先一步步写出推理过程，等于给了它更多轮计算——这是「思维链」能提升准确率的原因之一。

第 7 站 · Training

这些数字是怎么学来的

前面提到的所有数字——词向量、Q/K/V 的变换矩阵、前馈网络——统称参数。GPT-3 有 1750 亿个。一开始全是随机数，模型只会乱猜。

训练的规则简单得惊人：拿一段真实文本，遮住下一个词让模型猜；猜得越离谱罚得越重（惩罚叫损失，等于 −ln(正确答案的概率)）；再用反向传播算出每个参数该往哪个方向挪一点点，让正确答案的概率变大。在几千亿个 token 上重复这件事。

从「续写机器」到「助手」：三个阶段

阶段 1 · Pretraining

预训练

读海量网页、书籍、代码，只练「猜下一个词」。学会了语言、知识和推理的雏形，但它只是一个续写高手。

几千亿 ~ 十几万亿 token · 算力最贵的一步
阶段 2 · Instruction Tuning

指令微调

用人写的「问题 → 好回答」示范继续训练，让它学会：看到问题，该回答，而不是接着出题。

几万 ~ 几十万条示范
阶段 3 · RLHF 等

基于反馈的强化学习

让模型写多个回答，由人（或按原则打分的模型）评判哪个更好，再朝更有帮助、更诚实、更安全的方向调整。

GPT-3（2020）是架构细节公开得比较完整的大模型之一，拿它当标尺。后来的模型更大，但结构基本还是这一套。

新人最常见的几个误解

它在数据库里检索答案
没有数据库。知识被「压」进了 1750 亿个参数里，回答是一个 token 一个 token 现场生成的。
它不知道时会说不知道
第 5 站的 softmax 永远会给出一个分布，总有一个词「最像」。所以它可以流畅地编出不存在的书名——这就是幻觉。「说不知道」本身是后期训练额外教的行为。
它记得和你的每次对话
参数在训练结束后就固定了。它「记得」的只是当前上下文窗口里的内容；产品里的「记忆」功能，是把旧信息再塞回窗口。
它按字或字母读文字
它读的是 token（第 1 站）。所以数字母、倒写单词、做长数字的精确运算，对它来说反而比写文章难。
它是逐字背下来训练数据
参数量远小于训练文本的信息量，它只能学到规律和压缩后的知识；不过特别常见的段落（名言、开源许可证）确实可能被原样记住。

回到开头

文字切成 token→变成向量→词与词互相看+各自消化，重复 96 层→给 10 万个候选打分、挑一个→接回末尾，再来一遍

整个过程里没有一条规则是人写的。人只规定了结构和「猜下一个词」这个目标，剩下的——语法、常识、指代、推理——全都是为了猜得更准，从数据里自己长出来的。
