# 星际穿越 · 后来（Interstellar · Afterward）

《星际穿越》大结局的同人延展短片，时长 **1 分 53 秒**，1920×1080，24 fps。

原片的结尾是：库珀在土星轨道的库珀空间站与年迈的墨菲告别，然后驾驶一艘漫游者号（Ranger）
穿过虫洞，去找独自留在埃德蒙兹星球上的布兰德。这部短片接着讲**他到达之后**的事。

成片：`interstellar_afterward.mp4`

## 如何做出原片的质感

整部片子没有用任何素材或 AI 视频模型，每一帧都由代码算出来：

- **卡冈图雅是真的光线追踪**：按史瓦西度规积分每个像素的光子测地线
  （`x'' = -1.5 h² x / |x|⁵`，对应轨道方程 `u'' + u = 1.5u²`），所以吸积盘背面被引力
  弯折到黑洞上方和下方、那一圈细细的光子环，都是物理自然算出来的，和原片 Double Negative
  的做法是同一种思路。和原片一样，吸积盘去掉了多普勒不对称。
- **虫洞是一个球面透镜**：球内映出另一个星系被折叠的星空，球外的本地星空被引力拉成同心弧线。
- **地表是光线步进的高度场**：只渲染一次 G-buffer，再重新打光得到黄昏和夜晚两个版本，
  远山用大气透视淡出，地平线上的卡冈图雅会被台地遮住一角。
- **胶片后期**：2.39:1 遮幅（卡冈图雅段切换到 IMAX 满幅）、ACES 色调映射、高光溢出
  和红色光晕（halation）、变形镜头横向光条、胶片颗粒、暗角、逐帧轻微的片门抖动与曝光闪烁。
- **配乐完全原创、全部合成**：加性合成的管风琴（16'/8'/4' 等音栓）放在大教堂尺度的混响里，
  A 小调走到结尾的 C 大调；每 1.25 秒一次的滴答声取自米勒星球的设定，贯穿全片当作心跳；
  无线电对白前后有 NASA 的 Quindar 提示音；出虫洞那一刻整个声场被切断，再在黑洞前重新响起。

对白没有配音，以字幕呈现。

## 重新渲染

```bash
pip install numpy scipy numba pillow opencv-python-headless imageio-ffmpeg
python render.py                          # 画面 -> build/picture.mp4（4 核约 40 分钟）
python score.py                           # 配乐 -> build/score.wav
python render.py --preview 40,74,99       # 只出几张静帧预览
```

然后用 ffmpeg 合成音画：

```bash
ffmpeg -i build/picture.mp4 -i build/score.wav -c:v copy -c:a aac -b:a 256k -shortest interstellar_afterward.mp4
```

| 文件 | 作用 |
|---|---|
| `render.py` | 时间线、各个镜头、字幕 |
| `blackhole.py` | 卡冈图雅的测地线光线追踪 |
| `space.py` | 土星与虫洞、虫洞穿越、埃德蒙兹星球轨道 |
| `surface.py` | 地表高度场、打光、剪影绘制 |
| `lib.py` | 噪声、星空贴图、胶片后期、字幕排版、视频输出 |
| `score.py` | 配乐与音效合成 |
| `timeline.py` | 片长、对白字幕、滴答节拍 |
