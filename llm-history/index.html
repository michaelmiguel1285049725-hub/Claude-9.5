给新人的大模型发展史 · 续篇

从 GPT-1 到今天：
八年，七次换挡

上一篇讲的是「一个模型内部怎么运转」。这一篇讲「这台机器这八年是怎么被一步步改造的」。好消息是：核心几乎没变——直到 2026 年，最强的模型仍然是 Transformer，仍然在猜下一个 token。变的是喂给它什么、怎么训练它、让它花多少力气想、以及允许它动手做什么。

全景图谱：四条泳道，一百个节点 点任意圆点看详情 · 图可以左右拖动
OpenAI / ChatGPT Anthropic / Claude 开源（开放权重） 谷歌与学术界的关键论文

横轴不是匀速的：2022 年以前事件少，被压缩了；2022 年之后每一年都拉得更宽。大圆点是「换挡」级别的里程碑，读完全文你应该能说出每个大圆点改变了什么。

如果只记一件事，记这张表：八年里模型「变强」的来源一共换了七次挡，每一挡都是在前一挡快用完时接上的。

① 放大 2018–2020
同一个结构，参数、数据、算力一起放大一千倍，能力自己冒出来。
② 对齐 2022
不再只是变大，而是用人类反馈教它「当个助手」——ChatGPT 由此诞生。
③ 开放 2023
权重被公开，全世界都能在自家显卡上微调模型，技术扩散加速。
④ 更长、更全、更省 2024
上下文从几千到一百万 token；能直接听、说、看；混合专家让成本骤降。
⑤ 先想再答 2024.9–2025
用强化学习训练它先写一长段思考再作答：多花算力想，就答得更准。
⑥ 动手做事 2025
给它工具和循环：读文件、跑命令、点鼠标，从「回答问题」变成「完成任务」。
⑦ 能力分级 2026
最强模型强到能自己找网络漏洞，于是出现「公开版 + 受限版」分级发布，安全成了发布流程的一部分。

第 1 挡 · 2018–2020 · Scale

越大越聪明：GPT-1 到 GPT-3

2017 年谷歌发表 Transformer（你在上一篇第 3、4 站见过它）。OpenAI 做了一个当时看起来很朴素的决定：只拿 Transformer 的「解码器」那半边，在海量文本上练「猜下一个词」，然后不断放大。

2018.06

GPT-1 · 1.17 亿参数

证明了一个范式：先在大量书籍上预训练，再为具体任务（分类、问答）做少量微调。上下文只有 512 个 token。

2018.10

BERT（谷歌）

同期另一条路线：用 Transformer 的「编码器」做「完形填空」。它擅长理解，但不擅长写作，后来生成式路线胜出。

2019.02

GPT-2 · 15 亿参数

放大 10 倍后，出现了零样本能力：不做任何微调，只要把任务写成文字（比如在文章末尾加「TL;DR:」），它就会做摘要。OpenAI 因担心被滥用而分阶段公开权重，这是「AI 安全发布」争论的开端。

2020.01

缩放定律（Scaling Laws）

OpenAI 的 Kaplan 等人发现：模型的损失（上一篇第 7 站的「罚分」）随参数、数据、算力增加，按一条非常规律的幂律曲线下降。这等于说：「砸钱放大」的收益可以提前算出来。

2020.05

GPT-3 · 1750 亿参数

又放大 100 多倍。最大的惊喜叫上下文学习（in-context learning）：在提示里给它看几个例子，它就能照着做，不需要改任何参数。「提示词工程」从这里开始。

参数量：公开过的数字摆在一起

切到「真实比例」时 GPT-1、GPT-2 几乎看不见——这正是那几年的感受。注意 2023 年起，OpenAI 和 Anthropic 都不再公布参数量（GPT-4「1.8 万亿」只是传闻），所以图里 2023 年后的条目全是开源模型。浅色部分是混合专家模型的总参数，深色是每个 token 实际用到的「激活参数」（第 4 章细讲）。

新人要点：这一挡的全部秘诀就是「更大」。结构几乎没改，GPT-3 和 GPT-1 的零件你在上一篇都认识。但也埋下了问题：GPT-3 是个续写高手，不是助手——你问它问题，它可能接着出更多问题（上一篇第 7 站的「番茄炒蛋」例子）。

第 2 挡 · 2021–2022 · Alignment

学会听话：从续写机器到 ChatGPT

上一篇第 7 站讲过「预训练 → 指令微调 → RLHF」三阶段。这三个阶段不是一开始就有的，后两步正是 2022 年才被做成熟的，而它们带来的变化，比 GPT-2 到 GPT-3 的放大还要直观。

2021

Anthropic 成立

一批前 OpenAI 研究员（Dario 和 Daniela Amodei 等）出走创立，定位是「AI 安全公司」。这决定了 Claude 后来很多技术选择的底色。

2021.08

Codex

在 GitHub 代码上继续训练 GPT-3，驱动了 GitHub Copilot。第一次证明「会写代码」是大模型的杀手级用途。

2022.01

思维链提示（Chain-of-Thought）

谷歌发现：在例子里写出解题步骤，模型就会模仿「一步步推」，数学题正确率大涨。记住这个发现——它是第 5 章推理模型的种子。

2022.01

InstructGPT · RLHF

人类标注员对模型的多个回答排序，训练出一个「打分模型」，再用强化学习让 GPT-3 朝高分方向调整。结果：13 亿参数的 InstructGPT，比 1750 亿参数的 GPT-3 更受评估者喜欢——小 100 多倍，却更好用。

2022.03

Chinchilla（DeepMind）

修正了缩放定律：之前的模型「参数太多、数据太少」。算力固定时，每个参数大约配 20 个训练 token 最划算。此后各家都开始拼命找更多数据。

2022.11.30

ChatGPT

把 RLHF 用在对话上，再套一个免费的聊天网页。技术上不是最大的跃进，产品上却是引爆点：据报道约两个月达到 1 亿用户。ChatGPT 是产品名，它背后的模型之后换过很多代。

2022.12

宪法 AI（Constitutional AI）

Anthropic 的答案：与其让人给每个回答打分，不如写一份「宪法」（一组原则），让 AI 按原则批评、修改自己的回答，再用 AI 的评判做强化学习（RLAIF）。这是 Claude 的训练底座。

两种「教它听话」的流水线

新人要点：这一挡证明了「怎么训」和「多大」一样重要。从此每家公司的核心竞争力，一半在预训练，一半在后训练（post-training）——而后训练恰恰是外界最看不到的部分。

第 3 挡 · 2023 · GPT-4 · Claude · LLaMA

百花齐放：闭源冲顶，开源破圈

ChatGPT 之后的 2023 年，行业分成了两个阵营。闭源：只能通过网页或 API 使用，模型文件不公开（OpenAI、Anthropic、谷歌）。开放权重：把训练好的参数文件公开，谁都能下载、在自己的电脑上运行和改造（Meta、Mistral、阿里等）。

闭源阵营

2023.03.14

GPT-4

能力大跳跃：模拟律师资格考试成绩进入前 10%（GPT-3.5 在后 10%）。能看图（先对部分用户开放）。上下文 8K / 32K。技术报告几乎不披露任何架构和规模——从这里开始，前沿模型进入「黑盒」时代。

2023.03.14

Claude 1

和 GPT-4 同一天发布，第一个用宪法 AI 训练的公开模型，同时有一个更快更便宜的 Claude Instant。

2023.05

Claude 上下文 → 10 万 token

一次能读进一整本长篇小说。当时 GPT-4 最多 3.2 万。Claude 从此以「长上下文」出名。

2023.06

函数调用（Function Calling）

API 允许模型输出一段结构化的「我要调用某个函数，参数是……」，由程序去真的执行。这是第 6 章「智能体」的地基。

2023.07

Claude 2 → 2.1（11 月）

推出 claude.ai 网页；2.1 把上下文翻倍到 20 万，幻觉减半，并开始支持工具调用。

2023.11

GPT-4 Turbo

12.8 万上下文、价格大降。同年 9 月 ChatGPT 已能看图、听说语音。

2023.12

Gemini 1.0（谷歌）

谷歌第一个「从一开始就同时学文字、图像、音频」的原生多模态模型家族。

开源阵营：一次泄露引发的浪潮

2023.02

LLaMA（Meta）

70 亿到 650 亿参数，只对研究者开放，但一周后权重就在网上泄露。关键发现：130 亿参数的 LLaMA 在多数测试上超过 1750 亿的 GPT-3——因为它按 Chinchilla 的思路，用了多得多的数据。

2023.03

Alpaca / Vicuna

斯坦福用不到 600 美元，拿 GPT-3.5 生成的 5.2 万条指令数据微调 LLaMA-7B，得到一个「像 ChatGPT」的小模型。人人都能做微调的时代开始了。

2023.05

QLoRA / DPO

QLoRA 让一张 48GB 显卡就能微调 650 亿参数的模型；DPO 把 RLHF 简化成一步普通训练，不再需要单独的打分模型——开源社区终于也能做「对齐」。

2023.07

Llama 2

Meta 正式开放，并且允许商用，附带 RLHF 训练好的聊天版。企业从此可以合法地私有部署大模型。

2023.08–09

通义千问 Qwen · Mistral 7B

阿里的 Qwen 开始开源（后来成为全球下载量最大的开源家族之一）；法国的 Mistral 7B 用更聪明的注意力设计，以 70 亿参数打败 Llama 2 的 130 亿。

2023.12

Mixtral 8×7B

把混合专家（MoE）带进开源：总参数 467 亿，但每个 token 只动用约 130 亿。第 4 章你会亲手操作它。

LoRA：为什么普通人也能微调大模型 真实算术 · 一个 4096×4096 的权重矩阵

微调时不改原来那块巨大的矩阵 W（灰色，冻结），只在旁边训练两块又细又长的小矩阵 A 和 B，二者相乘就是对 W 的修正。r = 8 时要训练的数字只有原来的 0.4%，显存和训练成本随之骤降。LoRA 论文是 2021 年的，但真正火起来是在 2023 年的 LLaMA 浪潮里。

新人要点：「开源模型」通常指开放权重：参数文件公开，但训练数据和训练代码往往不公开。像菜谱没给，但做好的菜可以随便拿回家加工。

第 4 挡 · 2024 · Context · Multimodal · Efficiency

更长、更全、更省

2024 年没有一个像 ChatGPT 那样的单点爆炸，而是三条线同时推进：能读的更长（上下文窗口），能处理的更全（图像、语音原生进出），用起来更便宜（混合专家、蒸馏、小模型）。

上下文窗口：一次能「看见」多少 token 对数刻度 · 每格 ×10

回忆上一篇第 6 站：模型「记得」的只是窗口里的内容。窗口从 512 涨到一百万，约 2000 倍。换算参考：1 万 token 约等于 7500 个英文单词；10 万 token 大约是一本长篇小说；100 万 token 能装下一个中型代码仓库。窗口变长靠的是注意力算法的优化（如 FlashAttention）和位置编码的外推（如 RoPE 的扩展技巧）。

2024.02

Gemini 1.5 · 100 万 token

第一个把百万级上下文做成产品的模型，打开了长上下文竞赛。

2024.03

Claude 3 家族：Haiku / Sonnet / Opus

第一次把模型按「小快便宜 / 均衡 / 最强」分成三档，全部能看图、20 万上下文。之后各家都采用了这种分档做法。

2024.05

GPT-4o（o = omni，全能）

之前的语音模式是三段拼接：语音转文字 → GPT-4 → 文字转语音，平均延迟好几秒，还丢了语气。GPT-4o 是一个模型端到端直接吃进声音、吐出声音，平均响应约 320 毫秒，接近人类对话节奏，还能听出情绪、被打断。

2024.05

「百万特征」可解释性研究

Anthropic 从 Claude 3 Sonnet 内部提取出数百万个人类可理解的「特征」（比如一个专门对应「金门大桥」的方向），第一次在大模型里大规模看清「它在想什么」。

2024.06

Claude 3.5 Sonnet + Artifacts

中档价格超过自家顶档 Opus，编程能力大幅领先；「Artifacts」让代码和网页直接在对话旁边运行——你正在看的这种页面，就是这个功能的后代。

2024.07

GPT-4o mini

每百万输入 token 0.15 美元。对比 2023 年 GPT-4 刚发布时的 30 美元，同级能力的价格一年多降了约 200 倍。

2024.07

Llama 3.1 · 4050 亿参数

第一个在主要测试上接近 GPT-4 的开源模型，开源与闭源的差距从「一年多」缩到「几个月」。

2024.05 / 12

DeepSeek-V2 → V3

V2 发明了多头潜在注意力（MLA），把推理时占显存最多的 KV 缓存大幅压缩，引发中国大模型 API 价格战。V3：6710 亿总参数、每个 token 只激活 370 亿，用 FP8 低精度训练，论文称最终一轮训练只花了约 558 万美元（不含前期研究）。

混合专家（MoE）：参数很多，每次只用一小部分 示意 · 8 个专家选 2 个
点一个 token，看路由器把它派给谁

上一篇第 4 站里，每层有一个「前馈网络」负责消化信息。MoE 把它拆成很多个并排的专家，再加一个小小的路由器：每来一个 token，路由器只挑分数最高的 2 个专家干活，其余的休息。

好处：模型「知道」的东西由总参数决定，计算成本却只由激活参数决定。2025–2026 年几乎所有大型开源模型都是 MoE。

专家的分工是训练中自发形成的，通常不是「数学专家」「诗歌专家」这种人能读懂的分类，而更像按标点、代码语法、某类词形分工。图中的分工是简化示意。

2024.10

Computer Use（电脑操作）

升级版 Claude 3.5 Sonnet 能看屏幕截图、移动鼠标、敲键盘，第一次让通用模型直接「用电脑」。很笨很慢，但方向是对的——见第 6 章。

2024.11

MCP（模型上下文协议）

Anthropic 开源的一个统一「插头标准」，让任何模型都能用同一种方式连接任何工具和数据源。后来 OpenAI、谷歌都采用了它，2025 年底被捐给 Linux 基金会。

第 5 挡 · 2024.09–2025 · Reasoning

先想再答：推理模型

到 2024 年，「继续放大预训练」的收益开始变贵：好的文本数据快用完了，训练一次要上亿美元。于是出现了一个新方向——让模型在回答之前，先花更多 token 思考。这叫测试时计算（test-time compute）：算力不只花在训练时，也花在每次回答时。

关键是：结构没变，它仍然只是在猜下一个 token。只不过它被训练成先写出一长段「草稿」（思考过程），再写答案。草稿里的每一步，都成了后面 token 能「看见」的上下文。

同一道题：直接答 vs 先想再答 示意 · 经典的「球拍和球」陷阱题

球拍和球一共 1.10 元，球拍比球贵 1 元。球多少钱？

点上面任一按钮

直觉答案「0.10 元」是错的（那样球拍 1.10、合计 1.20）。直接答时，模型必须在写下第一个数字时就「一步到位」；先想再答时，前面写下的每一步都在帮它算后面的步骤。多出来的那几十个 token，就是测试时计算的全部含义。

2024.09.12

o1-preview：第一个推理模型

OpenAI 用强化学习训练模型产生长长的内部思维链。在数学竞赛和编程题上大幅超过 GPT-4o，而且思考时间越长越准。思考过程默认对用户隐藏。

2024.12

o3 预告

在专门测试「举一反三」的 ARC-AGI 上拿到高分，显示推理这条路还远没到头。2025 年 4 月正式发布，并能在思考过程中调用工具（搜索、运行代码、看图）。

2025.01.20

DeepSeek-R1：把配方公开

性能接近 o1，但权重和方法全部公开（MIT 协议）。最震撼的是 R1-Zero：跳过人写的示范，只用强化学习——做对数学题就给奖励——模型自己学会了反思、检查、推翻重来。一周后英伟达单日市值蒸发约 5890 亿美元，创美股纪录。

2025.02.24

Claude 3.7 Sonnet：混合推理

第一个「一个模型两种模式」的推理模型：可以秒答，也可以打开扩展思考并看到它的思考过程，开发者还能设定思考预算。2026 年演进为「自适应思考」——由模型自己决定这题要想多久。

2025.03

Gemini 2.5 · Qwen3（4 月）

推理成为标配。Qwen3 在开源模型里也做了「思考 / 不思考」一键切换。

2025.08.07

GPT-5：把两种模型合成一个系统

用户不再需要在「GPT-4o」和「o3」之间自己挑。一个实时路由器判断问题难度，简单的交给快模型，难的交给会深思的模型。

推理能力怎么「练」出来的：可验证奖励 + 组内比较 GRPO 的简化示意 · 数据随机生成

题目：12 × 15 = ? 让模型对同一道题写 8 份解答，程序自动核对最终答案。

每份解答的「优势」= 它的得分 − 这一组的平均分（再除以标准差）。高于平均的解答里的每一个 token 被调高概率，低于平均的被调低。注意：如果 8 份全对或全错，优势全是 0，这一组什么都学不到——所以训练题要选「有时做得对、有时做不对」的难度。这类方法统称 RLVR（可验证奖励的强化学习），适合数学、代码这种能自动判对错的领域。

新人要点：2022 年的 RLHF 靠「人觉得哪个好」打分，2025 年的推理训练靠「答案对不对」打分。后者可以无限自动化、不需要人，所以才能练出长达几万 token 的推理。

第 6 挡 · 2025 · Agents

动手做事：从聊天到智能体

智能体（agent）不是一种新模型，而是一种用法：把模型放进一个循环里——它想一步，输出一个「调用工具」的指令，程序真的去执行（跑命令、读文件、搜网页、点鼠标），把结果塞回上下文，它再想下一步——直到任务完成。

这个循环 2022 年就有论文（ReAct）和 2023 年的业余尝试（AutoGPT），但那时的模型跑十几步就会迷路。推理能力 + 长上下文 + 专门的工具使用训练凑齐之后，2025 年它才真正可用。

一个编程智能体修 bug 的全过程 示意 · 类似 Claude Code / Codex 的工作方式

每一个「行动」都是模型输出的一段结构化文字，由外面的程序执行；每一个「观察」都是程序把结果写回上下文。模型本身从头到尾只做一件事：猜下一个 token。

2026.09.03

GPT-6 Astra：循环深度

OpenAI 第一个在自家准备框架里被评为网络安全「关键」风险级别的模型，最敏感的能力需申请开放。技术上的新东西是循环深度（looped transformer）：同一组层对每个 token 反复走几遍，在内部「多想几轮」，而不全靠写出来的思维链。这引发了争议：推理藏进模型内部，人类就更难监督它在想什么。

三种「多想一会儿」的方式 示意

左：普通模型，每个 token 走一遍所有层（上一篇第 4 站）。中：推理模型，把思考写成可见的 token，算力花在「更长」。右：循环深度，把同一组层反复使用，算力花在「更深」，思考不留下文字痕迹。

新人最常见的几个误解

ChatGPT 就是一个模型
ChatGPT 是产品名。它背后的模型从 GPT-3.5 换到 GPT-4、4o、5、5.x，现在还会按问题难度自动路由。Claude 也一样，「Claude」是家族名。
新一代一定比上一代大很多倍
2023 年后前沿模型不再公布参数量。近几年的进步大多来自后训练、推理训练、工具使用和数据质量，而不只是变大。GPT-4.5（2025）这种「纯放大」的模型反而因为太贵被撤下了 API。
推理模型是一种新结构
o1、R1、Claude 的扩展思考，结构都还是 Transformer 猜下一个 token，只是用强化学习训练它先写思考再作答。2026 年的循环深度才第一次在结构上动了刀。
开源模型 = 所有东西都公开
绝大多数只公开权重。训练数据、数据清洗方法、完整训练代码通常不公开，所以你能用它、改它，但很难从零复现它。
上下文一百万，就能完美记住一百万
窗口越长，模型越可能漏掉中间的细节，成本和延迟也随长度上升。「装得下」和「用得好」是两回事，这也是各家持续优化的地方。
智能体是一个会自己思考的新 AI
智能体 = 模型 + 工具 + 循环。模型负责决定下一步，外面的程序负责真的执行。能力边界取决于给了它哪些工具、允许它做什么。

术语小词典

回到开头

放大→对齐→开放→更长·更全·更省→先想再答→动手做事→分级发布

每一挡都没有取代前一挡，而是叠在上面：今天的模型仍然要大规模预训练，仍然要对齐，仍然要便宜，然后再学会推理、再学会用工具。下一次你看到一个新模型发布，可以问自己：它在哪一条主线上往前走了？
