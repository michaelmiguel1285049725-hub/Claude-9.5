# 思考流水线地图（Pipeline Map）

认知偏差知识地图的交互式可视化，按 `PLAN.md`（方案 1）实现，数据严格来自 `bias_map_data.json`（101 个节点、35 条边，未增删）。

- 页面在仓库根目录 `index.html`（方便 GitHub Pages 直接从根目录发布），直接用浏览器打开即可；无构建步骤，无依赖（字体来自 Google Fonts，离线时回退到系统中文字体）。
- `bias_map_data.json` — 数据源。页面内嵌了一份同样的数据；修改数据后需重新注入 `<script id="data">` 中的 JSON。
- `PLAN.md` — 设计方案。

## 布局对照

| 方案 | 实现 |
|---|---|
| 主轴五站 ①–⑤ | 色带内顶部一行，① ④ 仅为流程标记 |
| B / C / F 区 | ② ③ ⑤ 站下方的网格（按数据顺序纵向填充，派生关系上下相邻） |
| D / E 区 | 主轴上方两簇，箭头指向 ② ③ |
| G 区 | 主轴背景渐变色带（左浅右深），8 个概念作为色带底部的标注 |
| H 区 | 每站周围的散布晕；4 个概念放在右上"H · I 区"图例面板 |
| I 区 | 图例中的三种节点样式；4 个概念放在同一图例面板，refuted 保留为灰色删除线 |
| J 区 | 主轴下方的方块，虚线按 `edges` 连到作用对象 |
| A 区 | 底部横贯的长条 |
| 反馈回路 | ⑤ → ② 虚线，在色带深色段断开 |

## 交互

- 三级缩放：骨架（只有站名、区名、图例）→ 节点名 → 一句话；滚轮缩放、拖动平移，`+` / `-` / `Esc`。
- 图层：只看卡尼曼 / 按学派筛选 / 只看硬证据（隐藏 contested、refuted）。
- 点击节点：侧边卡片（中英文名、一句话、出处、证据状态、相连节点可跳转）。
- 悬停站名：高亮该站节点及连到它们的去偏方法。
