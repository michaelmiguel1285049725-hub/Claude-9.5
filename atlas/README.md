# atlas · 领域学习地图引擎

一套纯静态网页，读取一个"内容包"（JSON），渲染出三个联动的视角：**关系网**、**成熟度地图**、**时间线**。引擎里不包含任何具体领域的内容，换一个内容包就是另一张地图。

线上地址（部署后）：`https://michaelmiguel1285049725-hub.github.io/Claude-9.5/atlas/`

- 默认打开 `ai-bias` 内容包。
- 打开别的内容包：在地址后面加 `?pack=内容包编号`，例如 `…/atlas/?pack=munger`。

---

## 1. 目录里有什么

```
atlas/
  index.html            页面入口
  css/                  样式（tokens.css 是颜色和字体变量，app.css 是布局）
  js/                   引擎代码（不用改）
  packs/
    ai-bias/
      pack.json         内容包：节点、关系、空缺问题
  tools/validate.mjs    命令行校验工具
  package.json          只是为了让校验工具能在 Node 里运行，不需要 npm install
  PLAN.md、PLAN-v2.md   两次开发的实施计划
```

---

## 2. 怎么替换或更新内容包

1. 把新的 JSON 原样保存为 `packs/ai-bias/pack.json`（覆盖旧的）。
2. 跑一遍校验（见第 3 节）。
3. 提交、推送，等 GitHub Pages 更新（通常一两分钟）。

内容包的格式见 `PLAN.md` 或原始任务书第 5 节。简单说：`domain`（标题、研究线、时间轴分段）、`nodes`（节点）、`edges`（关系）、`gaps`（空缺问题）四部分。

**注意**：学习进度、Notion 链接、拖动过的节点位置、筛选偏好都存在浏览器的 localStorage 里，按内容包编号（`pack_id`）分开。换内容包不会互相影响；但换电脑或清浏览器数据会丢，它们不在仓库里。

---

## 3. 怎么跑校验

需要电脑上装有 Node.js（任何近几年的版本都行）。在终端里进入 `atlas/` 目录，运行：

```
node tools/validate.mjs packs/ai-bias
```

输出会列出节点、关系、空缺的数量，然后是"提示"（不影响渲染）和"错误"（必须修）。有错误时退出码是 1。

页面加载时也会自动跑同一套规则：有错误就在页面顶部显示一条红色提示条，逐条列出问题；能画的部分照常画。

八条规则：所有 id 唯一；关系的两端和空缺引用都必须存在；枚举值合法；一句话 ≤ 20 字、理由 ≤ 24 字；年份是 1900–2100 的整数；节点的研究线必须在 `domain.clusters` 里；依据为"加工"的关系必须有 `ref`；同一对节点之间同一类型的关系不重复。

---

## 4. 关系网的布局怎么定

关系网的位置完全由内容包决定，不需要也不能手动拖动：

- 每条研究线一个区域，区域的大致位置由 `domain.clusters[].anchor` 决定（0–1 的相对坐标，横向分左 / 中 / 右三列，同一列按纵坐标上下排）。
- 区域里的节点按 `year` 从早到晚排，列数按节点数自动定：3 个以下 1 列，4 到 8 个 2 列，9 个以上 3 列。

想调整某条研究线的位置，改它的 `anchor` 即可。改版 1 里的"导出布局"、`layout.json`、拖动固定已经删除。

---

## 5. 怎么新增一个领域

1. 在 `packs/` 下新建目录，目录名就是内容包编号，只能用小写字母、数字和连字符，例如 `packs/munger/`。
2. 把内容包保存为 `packs/munger/pack.json`，里面 `domain.pack_id` 也写 `munger`。
3. 校验：`node tools/validate.mjs packs/munger`。
4. 打开 `…/atlas/?pack=munger`。

研究线的颜色由引擎按 `clusters` 的顺序从一组低饱和色板里分配（最多 8 个不重复，超过循环使用）。如果你想指定颜色，可以在某条研究线上加一个可选字段 `"color": "#6F86B3"`。

## 6. 页面上怎么操作

- **顶栏一行**：视角切换（键盘 `1` `2` `3`）、搜索、"只看有文献来源"开关、筛选抽屉、空缺、图例、进度圆环、`?` 操作提示、深浅色。切换视角时选中的节点保持不变。
- **关系网三个层级**：
  - 全览：每条研究线一个区域，节点按年份排列；默认不画节点之间的线，只画研究线之间的汇总连线（数字 = 关系数，悬停看分项）。悬停节点临时看它的全部关系。
  - 研究线聚焦：点区域标题或空白处，放大到这条研究线并画出内部关系；悬停节点看它的跨线关系伸向哪条研究线。
  - 关系透镜：点任意节点。中心是这个节点，左栏"指向它的"，右栏"它指向的"，按关系类型分组。点侧边卡片换中心，点线看关系详情，点中心看节点详情。左上角的路径导航记录你走过的节点，"复制这条路线"能把它变成文字。
  - `Esc` 逐层返回。"简化为研究线"开关只画六个气泡。
- **筛选抽屉**对三个视角同时生效；抽屉里的"全览中显示全部关系线"能恢复画全部线的样子。
- **成熟度地图**：格子里的卡片字号不低于 12px，放不下时网格内滚动，行列标题固定。点节点看它和其他格子的关系弧线，面板里可"在关系透镜中打开"。
- **时间线**：泳道名固定在左侧；默认只画同泳道的继承 / 支持 / 挑战 / 修正弧线，悬停或选中节点才画跨泳道弧线；"逐步展开"按年份一步步看。
- **找路径**：筛选抽屉里点"找路径"，再依次点两个节点，结果是横向链条，点链条里的节点进入透镜。
- **空缺**：顶栏"空缺"列出全部空缺问题，点一个进入它第一个节点的透镜，属于它的关系加粗。
- **搜索**：按 `/`，输入编号（`c4`、`c04`、`C-04` 都行）或名称，直接进入透镜。
- **节点面板**："复制给 Claude 的提问"生成讲解请求；"Notion 链接"记住这个节点对应的页面；"标记已消化"记录学习进度。
- **地址栏**记录当前视角、层级、透镜里走过的路径、选中的关系 / 空缺 / 路径，可以直接当书签；浏览器后退键回到上一个状态。
- **主题**：跟随系统深浅色，◐ 手动切换。
- 其他快捷键：`+` `-` 缩放，`0` 适配全部，时间线故事模式下 `←` `→` 上一步 / 下一步。

## 7. 技术说明

- 纯 HTML + CSS + 原生 JavaScript（ES modules），无构建步骤。
- 唯一的外部依赖是 D3 v7.9.0，从 `cdn.jsdelivr.net` 加载（版本已锁定）。没网时页面会提示 D3 未能加载。
- 本地预览：在 `atlas/` 目录运行 `python3 -m http.server 8765`，打开 `http://127.0.0.1:8765/`。直接双击 `index.html` 打不开，因为浏览器不允许 `file://` 下用 fetch 读 JSON。
- 部署：GitHub Pages 工作流（`.github/workflows/pages.yml`）在推送到 `claude/new-session-sefln5` 或 `main` 分支时发布整个仓库，`atlas/` 目录随之上线。
