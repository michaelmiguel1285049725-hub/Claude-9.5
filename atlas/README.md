# 领域学习地图（atlas）

一套可以反复使用的"学习地图"网页。网页本身不写任何领域内容，所有节点、关系、空缺问题都来自一个**内容包**（`pack.json`）。换一个内容包，就是另一张地图。

- 线上地址：`https://michaelmiguel1285049725-hub.github.io/Claude-9.5/atlas/`
- 当前内容包：`packs/ai-bias/pack.json`（AI × 认知偏差 × 决策）

---

## 一、怎么看这张地图

顶栏从左到右：标题（鼠标停上去看副标题和版本）、三个视角、搜索、找路径、筛选、空缺、"只看文献来源"开关、图例、深浅色。

**关系网（默认）分三层，像地图从省放大到市再到街道：**

1. **全貌**：6 个研究线气泡。线越粗、圆里的数字越大，两条研究线之间的关系越多。
2. **研究线展开**：点一个气泡，它的节点排成整齐的网格；其他研究线缩到画布四周。鼠标停在节点上，看它连向哪里。
3. **关系透镜**：点一个节点，它到中间，左边是"指向它的"，右边是"它指向的"，按关系类型分组。点左右任一个节点，它移到中心，继续往下走。

左上角的路径导航记录你走过的节点，点任意一段可以回去；"复制这条路线"会把它变成一行文字。

**另外两个视角：** 成熟度（按证据等级 × 拥挤度摆放）、时间线（按年份和研究线摆放）。在任一视角里选中的节点，换视角后仍然选中。

**常用操作：**

| 操作 | 方法 |
|---|---|
| 切换视角 | 键盘 `1` `2` `3` |
| 搜索 | 按 `/`，输入编号（如 `c4`）或名称，回车直接进入透镜 |
| 返回上一层 | `Esc`（先关掉打开的抽屉，再逐层返回） |
| 看节点详情 | 在透镜里点中间的大卡片 |
| 讲解提问 | 节点详情里点"复制给 Claude 的提问"，粘贴到和 Claude 的对话里 |
| 学习进度 | 节点详情里点"标记已消化"；全貌气泡外圈的绿弧就是进度 |
| Notion 链接 | 节点详情里粘贴这个节点的 Notion 页面地址，保存后变成"在 Notion 打开" |
| 找路径 | 顶栏"找路径"，填起点和终点；结果是一行行横向链条 |

学习进度、Notion 链接、筛选偏好只保存在当前这台电脑的这个浏览器里，换浏览器或清除网站数据后会没有。

## 二、在自己电脑上预览

因为网页要读取 `pack.json`，直接双击 `index.html` 打不开。在仓库根目录（`Claude-9.5` 文件夹）里运行：

```
python3 -m http.server
```

然后在浏览器打开 `http://localhost:8000/atlas/`。按 `Ctrl + C` 停止。

---

## 三、检查内容包有没有写错

改完 `pack.json` 后，在 `atlas` 文件夹里运行：

```
node tools/validate.mjs packs/ai-bias
```

- 显示 `✓ 校验通过` 就没问题。
- 有问题会逐条列出：哪条数据、哪个字段、什么问题。例如 `E-07 · to · 指向不存在的节点「X-99」`。

网页打开时也会做同样的检查。有问题时页面顶部出现一条红色提示条，能画的部分照常显示。

检查的规则：编号不能重复；关系两端的节点、空缺编号必须存在；类型、状态等只能用规定的取值；一句话（gist）不超过 20 字，关系理由（reason）不超过 24 字；年份在 1900–2100 之间；节点的研究线必须存在；"加工"的关系必须填 ref；同一对节点之间同一类型的关系不能重复。

## 四、替换内容包

1. 用新的 JSON 整个替换 `packs/ai-bias/pack.json`。
2. 运行上面的校验命令，确认通过。
3. 提交到 GitHub 上负责发布网站的分支（目前是 `claude/new-session-sefln5`），几分钟后线上地址自动更新。

内容包的四个部分：`domain`（标题、研究线、时间轴分段）、`nodes`（节点）、`edges`（关系）、`gaps`（空缺问题）。字段说明见最初的设计文档第 5 节，或者直接参照现有的 `pack.json`。

研究线的颜色按 `domain.clusters` 里的顺序自动分配。想指定某条研究线的颜色，可以在它里面加一个 `"color": "#7d8fa8"`。

---

## 五、新增一个领域

1. 在 `packs` 里新建一个文件夹，名字就是这个内容包的编号，例如 `packs/munger/`。编号只用小写字母、数字、`-`、`_`。
2. 把新内容包存成 `packs/munger/pack.json`，里面的 `domain.pack_id` 也写 `munger`。
3. 校验：`node tools/validate.mjs packs/munger`
4. 打开网址时在后面加 `?pack=编号`：
   `https://michaelmiguel1285049725-hub.github.io/Claude-9.5/atlas/?pack=munger`

不加 `?pack=` 时默认打开 `ai-bias`。每个内容包的学习进度、Notion 链接、筛选各自分开保存。

---

## 六、布局是怎么定的

改版 1 之后，关系网不再用可拖动的力导向图，所以没有"固定布局"这一步，也不再读取 `layout.json`：

- **全貌**：气泡位置来自内容包里每条研究线的 `anchor`（0–1 的相对坐标，换算到画布上）。想挪动某个气泡，改它的 `anchor`。
- **研究线展开**：按年份（或按节点类型）排成网格，同样的数据每次位置都一样。
- **关系透镜**：按关系类型和研究线的固定顺序排列。

## 七、文件说明

```
atlas/
  index.html              页面入口
  css/tokens.css          颜色、字体等设计变量（浅色 / 深色）
  css/app.css             页面样式
  js/main.js              启动、全局状态、按钮与快捷键
  js/state.js             全局状态与订阅
  js/data.js              读取内容包、建立索引
  js/validate.js          校验规则（网页和命令行共用）
  js/encoding.js          视觉编码表：关系类型颜色、状态线型、证据等级等
  js/glyph.js             节点卡片、角标、箭头的画法（各视角共用）
  js/filters.js           筛选规则与筛选抽屉
  js/legend.js            图例（只列当前画面出现的东西）
  js/panel.js             右侧详情抽屉
  js/search.js            搜索
  js/pathfinder.js        找路径的算法
  js/trail.js             路径导航与"复制这条路线"
  js/hash.js              把当前状态写进网址，刷新后恢复
  js/storage.js           本机存储（学习进度、Notion 链接、筛选）
  js/tooltip.js           悬停提示
  js/views/network.js     关系网：在三层和找路径之间切换
  js/views/net-overview.js  第一层：研究线概览
  js/views/net-cluster.js   第二层：研究线展开
  js/views/net-lens.js      第三层：关系透镜
  js/views/net-path.js      找路径的横向链条
  js/views/maturity.js    成熟度地图
  js/views/timeline.js    时间线
  js/views/shared.js      三个视角共用的高亮、提示、画线工具
  packs/ai-bias/pack.json 内容包
  tools/validate.mjs      命令行校验
```

网页用 D3 v7（从 cdn.jsdelivr.net 加载，版本锁定为 7.9.0），不需要任何构建步骤。
